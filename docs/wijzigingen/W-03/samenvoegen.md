# W-03 — samenvoeg-instructie (hoofdsessie)

Na akkoord van Jurgen worden de bevroren documenten aangevuld met **alleen** deze vier samengevoegde invoegteksten (elk met per blok de doelplek). Alle eerdere rondes (`*-r1` … `*-r6`, `r4b`, `r4c`) zijn archief.

| Document | Invoegtekst |
| --- | --- |
| PRODUCT_SPEC.md en ACCEPTANCE_CRITERIA.md | `samengevoegd/PRODUCT_SPEC-en-ACCEPTANCE_CRITERIA.md` (blokken "=== PRODUCT_SPEC.md ===" en "=== ACCEPTANCE_CRITERIA.md ===") |
| UX_SPEC.md | `samengevoegd/UX_SPEC.md` (nieuwe §13 na §12) |
| TECHNICAL_DESIGN.md | `samengevoegd/TECHNICAL_DESIGN.md` (§18, §15-regels, aanvullingen per sectie) |
| DESIGN_SYSTEM.md | `samengevoegd/DESIGN_SYSTEM.md` (blokken 1a–1c, 2, 3, 4a–4b) |

Rapporttekst boven en onder de blokken (verslagen, wijzigingslijsten, vragen, interpretaties) wordt niet ingevoegd; de interpretaties gaan naar het totaalvoorstel aan Jurgen.
